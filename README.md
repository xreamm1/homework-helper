# Помощник по домашке

Минималистичное веб-приложение: вводите условие задачи (текстом или фото) и получаете пошаговое объяснение. Цель — помочь понять материал, а не просто выдать ответ.

Каталог устроен как на школьных порталах: **класс → предмет → задача** (1–11 классы, 15 предметов). Класс и предмет передаются в запрос, поэтому объяснение подстраивается под программу. Готовых ответов чужих сайтов здесь нет: решение объясняется заново, а не берётся из базы.

Один файл `index.html` (около 29 КБ), чистый HTML + CSS + JS, без сборки, фреймворков, рекламы и трекеров.

## Возможности

- Ответ в три части: **идея решения → шаги с пояснениями → проверка ответа**.
- Режим **«Подсказка по шагам»**: сначала виден только первый шаг, следующие открываются по кнопке.
- Ввод текстом или **фото** (снимок сжимается в браузере до 1568 px).
- Формулы через [KaTeX](https://katex.org): библиотека подгружается с CDN (с SRI-проверкой) только если в ответе есть формулы.
- Тёмная и светлая тема (`prefers-color-scheme`), адаптивная вёрстка для телефона.

## Использование

1. Выберите класс и предмет (ссылки вида `#/7/alg` можно сохранять в закладки).
2. Откройте страницу (GitHub Pages или локально `index.html`).
3. В блоке «Настройки» вставьте свой ключ [Anthropic API](https://console.anthropic.com/) и при желании поменяйте модель.
4. Введите задачу или прикрепите фото и нажмите «Объяснить». `Ctrl+Enter` тоже отправляет.

## Приватность

- Ключ API и история (последние 20 задач) хранятся **только в `localStorage` вашего браузера**.
- Запросы уходят напрямую из браузера в `api.anthropic.com`, без промежуточных серверов. Фото в историю не сохраняется.
- Запросы выполняются с `cache: "no-store"`, без cookies и referrer.
- Политика Content-Security-Policy в `index.html` разрешает сетевые обращения только к `api.anthropic.com` и `cdn.jsdelivr.net` (KaTeX).
- Приложение не использует чужие базы решений и не парсит сторонние сайты.
- Текст задачи и фото передаются в Anthropic API; их обработка регулируется условиями вашего аккаунта API.

Важно: ключ вводит сам пользователь, а заголовок `anthropic-dangerous-direct-browser-access` включает вызов API из браузера. Не вшивайте в страницу общий ключ.

## Как устроено

| Часть | Что делает |
| --- | --- |
| `askModel(problem, mode, {image, signal})` | запрос к API, таймаут 90 с, отмена, понятные сообщения об ошибках |
| `parseAnswer(text)` | разбирает ответ на идею, шаги и проверку по маркерам `### ШАГ n` |
| `renderSteps(text, mode)` | безопасный вывод через `createElement` и `textContent`, без `innerHTML` для текста; в режиме подсказки шаги добавляются в DOM по одному |

## Запуск локально

Сборка не нужна: откройте `index.html` в браузере или поднимите любой статический сервер, например `python3 -m http.server`.
